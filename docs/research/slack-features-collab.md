# Slack desktop client feature inventory: collaboration and platform

Parity checklist for slackless, covering the collaboration and platform features of the official Slack desktop app (macOS, Windows, Linux) as of November 2026. Each line is one checkable feature in the form `F-COLLAB-NNN <name> - <behavior to verify> - OBSERVED: <source>`. Indented sub-bullets list notable variants of the feature above them.

Sources:

- Slack Help Center articles (https://slack.com/help), crawled per topic plus one hop of linked articles.
- The Slack changelog (https://slack.com/help/articles/115004846068-Slack-updates-and-changes), November 2024 to November 2026, used for recently added features.
- The slack.com/features pages and the Slack developer docs (https://docs.slack.dev) for Block Kit, modals, App Home, unfurls, shortcuts, slash commands, Work Objects, agents and the Calls API.
- The Mac and Windows desktop release notes (https://slack.com/release-notes/mac and /windows). I scanned them for the same window, but they announce no features there (only security and bug-fix notes such as a huddle screen-share crash fix), because features ship server-side. That's why the changelog is the source for recent additions.

Pages for workspace administration, billing, SSO, exports and analytics are left out unless a setting changes what members see or can do in the client. Where that happens, the rule is listed as a single line. Mobile-only behaviors are also excluded.
