## What wave E contains (apps/slackless-gui/src)

| Module                    | Surface                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Talks to Slack?                                                                                                                  |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `emoji.rs` (809 lines)    | The shortcode catalog that reaction chips, rich text, mrkdwn and statuses resolve through. Supports skin-tone suffixes (`wave::skin-tone-3` with Fitzpatrick modifiers) and aliases, and draws custom emoji as images. `EmojiPicker` has a search field (Enter picks the first hit), a skin-tone selector, 9 category tabs (Frequently used first, Custom last), a scrolling grid and a hover preview. One picker serves the composer and add-reaction, routed by the root.                                                                                                                                                        | No. Frequently used is kept in memory and custom emoji come from fixtures.                                                       |
| `blockkit.rs` (661 lines) | Renders the `Block::Unknown` JSON for `section` (text, fields, accessory), `divider`, `image`, `context`, `header`, `actions` and `input`. The elements are gpui-kit widgets: buttons (primary, danger and default; url buttons open the browser), selects (static, external, users, conversations and channels, plus their multi variants), overflow, datepicker, timepicker, checkboxes, radios and text inputs. Other block types show a "cannot show yet" line. Legacy attachments get a color bar, pretext, author, linked title, mrkdwn text, short and long fields, nested blocks, an image, and a footer with a timestamp. | No. An interaction updates the local `BlockKitState`, writes a line to stderr and shows a toast, and no `block_actions` is sent. |
| `actions.rs` (429 lines)  | One action set shared by `messages.rs` and `threads.rs`. The hover toolbar has three quick reactions, Add reaction, Reply in thread, Forward, Save for later and More. The full menu (from More or a right-click) has an Add reaction submenu, Reply, Copy link, Forward, Save, Mark unread, Edit and Delete. Also here: reaction chips (toggle and add), the inline edit box, and the saved banner.                                                                                                                                                                                                                               | Fixture mutations only. Forward shows a "needs a live workspace" toast.                                                          |
