## Edits made to api-activity.md

1. **Conventions › Transport.** Added the evidence that the web client calls the workspace host (findings.md:22). Added a Host sub-bullet: gammons takes the API base from `auth.test`'s `url`; Enterprise Grid needs `https://<org>.enterprise.slack.com/api/`; gammons and emacs-slack fall back to `slack.com`, and wee-slack uses `api.slack.com` (gammons client.go:78,391-399,436-443). Added a Token-placement sub-bullet: emacs-slack and ericboehs send `Authorization: Bearer`, and gammons warns that this triggered Grid anomaly detection (client.go:1836-1847).
2. **Conventions › Body encoding.** Noted that emacs-slack sends `:params` as URL query parameters, so its POSTs here have empty bodies; activity.feed is the exception (slack-request.el:201-209; request.el:348,505-508).
3. **Source pins.** Added `tkf/emacs-request` at `c22e3c23a6dd90f64be536e176ea0ed6113a5ba6` so the request.el citations are reproducible.
4. **subscriptions.thread.clearAll › Transport.** Replaced "form body" with the observed query-parameter form plus citations, and moved the form-body claim to LEADS.
5. **activity.feed › `types`.** Changed "sent by every client" to optional, citing ericboehs activity.rb:12-16. Added gammons' official-client list under its own activity.go:17-20 cite, and dropped that cite from the emacs-slack-only list lines.
6. **activity.feed › `archive_only`.** Added clack ACTIVITY.md:40 (Clear = `activity.archive`) to the cite.
7. **activity.feed › Response.** Widened the cite from activity_feed.json:6-16 to 4-23 so it covers is_archived, is_bot and version.
8. **activity.markUnread › Transport.** Widened the cite from activity.go:453-456 to 453-461 so it includes the postForm call.
9. **activity.views › Transport.** Replaced the asserted POST with no params by "not observed; standard form POST presumed", and moved the claim to LEADS.
10. **users.prefs.setNotifications › sound example.** Added the empty `_x_reason=` that the capture shows (notification-presentation-protocol.md:57-64).
11. **dnd.setSnooze › Transport.** Noted that the docs accept url-encoded or JSON, slackgo sends a form and ericboehs sends JSON with Bearer, and added cites (dnd.go:46-48; slack.go:271-272; api_client.rb:62-71).
12. **dnd.teamInfo › Transport.** Changed POST to GET per the docs and emacs-slack (slack-request.el:69), with POST only in slackgo.
13. **update_thread_state › When.** Reworded to what clack NATIVE.md:204-214 shows, and moved the "current web client" claim to LEADS.
14. **badge_counts_updated › Official handling.** Widened the cite from notification-presentation-protocol.md:448-459 to 442-459.
15. **activity › Subtypes.** Kept the three subtypes that clack names (cite 45-47). Moved activity_clear_all_completed and activity_views_updated to a separate "also handled" list, and moved their subtype claim to LEADS.
16. _\*dnd_* › Effective DND._* Added gammons' `next_dnd_start_ts > 0` guard (events.go:958).
17. **LEADS.** Added four "unverified:" entries for the moved claims: update_thread_state currency, the activity subtypes, the clearAll form body, and the activity.views transport.
