## Edits to api-search.md

1. `### search.modules.channels`, the `sort` / `sort_dir` bullet: the Sort-select list is now mapped to the wire pairs: `relevant/desc`, `created/desc`, `created/asc`, `member_count/desc`, `member_count/asc`, `name/asc`, `name/desc`. Browse-mode sorts are spelled out: `recommended` by default, or `name`/`created`/`member_count` with a `sort_dir`. Added cites: clack search.go:565-571, clack browse.go:663-676, slackdump internal/edge/search.go:150-151.
2. `### search.modules.people`, the sort bullet: now maps to `relevant/desc`, `name/asc`, `name/desc`. Added cite: clack search.go:88-115.
3. `### search.precache`, Transport: kept "shared transport" and added the evidence, because the old cite (types.ts:25527) only names the method. Added cites: undoc src/client.template.ts:223-252, gist.md:77-79, gist.md:509.
4. `### search.messages`, Transport: the miscited "A session client posts to `https://<ws>.slack.com/api/search.messages`" now says emacs-slack POSTs to `https://slack.com/api/search.messages` and clack to the team host. Cites: emacs-slack slack-search.el:216-217 and 249-257, clack more.go:357 and client.go:492-497, redoc block-actions-and-modals-2026-09.md:114.
5. `### edgeapi users/search`, Transport: added slackdump cites for the body `token` (edge.go:166-168, 208-216). Also added that clack sends the same token as both `token` and `enterprise_token`, appends `?_x_app_name=client` and posts `text/plain;charset=UTF-8` (client.go:583-601), and that karbassi lists `enterprise_token` as required on Enterprise Grid (undocumented-endpoints.md:81). This is an addition; the old text was correct.
6. `## Gotchas`, the "Prior art" bullet had two problems:
   - "slack-go uses only the public methods" is contradicted by slack-go's own Edge `users/search` (search.go:181-194).
   - "mautrix-slack calls no `search.*` method" was cited to go.mod:48, which only shows the fork pin. A grep of mautrix/slack@38d69d5d confirmed it: the only search call is slack-go's `SearchUsersCacheContext`, at pkg/connector/startchat.go:187-191.

   Both are rewritten with those cites, and "Every private detail" now reads "Most private details".
